# 43030_Professional_Learning
**About This Repository**
This repository documents my professional learning and skill development as part of 43030 Professional Practice in Computing at the University of Technology Sydney (UTS).

I am currently studying a Bachelor of Computer Science, majoring in Cybersecurity and Privacy. My career goal is to become a Junior Software Developer, with a long-term ambition of working as a Front-End Software Engineer.

**My Learning Goals**
GitHub and Version Control: Improve my understanding of Git, GitHub repositories, branching, commits, pull requests, and collaborative development workflows.

Frontend Development: Develop practical skills in JavaScript and React, including reusable components, state management, and interactive web applications.

Cybersecurity and Secure Coding: Apply cybersecurity principles to software development, focusing on data protection, secure coding practices, and preventing common web vulnerabilities.

Professional Development: Strengthen my problem-solving, documentation, communication, and ethical decision-making skills to prepare for a career in the IT industry.

**Purpose**
The purpose of this repository is to track my learning progress, practise professional software development techniques, and build a portfolio demonstrating my technical skills.

This repository will be updated as I complete practical exercises and development projects.
